题目：[1569. 将子数组重新排序得到同一个二叉搜索树的方案数](https://leetcode.cn/problems/number-of-ways-to-reorder-array-to-get-same-bst/)（每日一题）

![题目截图](/images/leetcode/1569-1.png)

这道题是想找出二叉搜索树与给出的形状相同的不同数组的数目，二叉搜索树(BST)是一种特殊的二叉树，它的左子树的所有节点都比根节点小，右子树的所有节点都比根节点大。

从一个确定的数组可以构建出一个确定的二叉搜索树，构建流程是：从根部开始搜索，如果当前节点大就进入右子树，如果当前节点小就进入左子树，直到找到一个空位置然后填上。因此数组的前后顺序会影响树的形状。

如何使树的形状不变呢？

以示例1为例，不难看出2一定要在第一个位置，而1和3可以任意组合，\[2,1,3\]和\[2,3,1\]构建出来的树都是一样的：\[2,1,3\]会将2作为根节点，然后1比2小，放在2的左子树，3比2大，放在2的右子树；同理\[2,3,1\]会将2作为根节点，然后3比2大，放在2的右子树，1比2大，放在2的左子树。这里可以总结出一个规律，**数组的第一个数字一定是根节点，根节点的左右子节点顺序不影响二叉搜索树的形状**。

以示例2来验证一下：

第一个数字一定是3，然后1和4可以任意选择，假设我们选择1之后，则2和4可以继续任意选择，我们再次选择4，则2和5可以任意选择。最终我们可以得到六种选择，去掉题目给的数组，一共5种选择。不难看出这是一种回溯的思路，选择一个节点之后将他的左右节点加入到答案的候选中，然后从候选中挑一个，再次加入候选，重复这个过程，就可以得到一种答案。通过不断回溯，可以获取所有的答案。

当前这里有更好的解法，省去了回溯的过程，可以通过组合数直接得到答案：以示例2为例，3的左右子树分别是\[1,2\]和\[4,5\]，这里左右子树各自的方案是固定的，1和2、4和5必须要保持前后顺序：即2不能在1前面，5不能再4前面。然后我们要判断有多少种组合方案，其实就是一个四选二的过程，可以看作从空着的四个位置里选择两个位置放左子树的节点(四个里面一把抓两个，也可以理解成给每一次挑一个位置，第二次再挑一个位置，然后去掉第一次的位置在第二次之后的情况，4\*3\/2   (等差数组求和，3+2+1))，一共有六种情况，分别是4512,4152,4125,1452,1425,1245。假设左右子树各自的方案的(子树内部方案)分别为C_l和C_r，在这个例子里都是1，然后计算方案数=C_l \* C_r \* (\frac{len(left), len(right)})。

> 组合数可以通过杨辉三角来计算出来保存，避免多次计算

![示例 2 截图](/images/leetcode/1569-2.png)

```go
func numOfWays(nums []int) int {
	const MOD = 1_000_000_007
	n := len(nums)
	dp := make([][]int, n)
	for i := 0; i < n; i++ {
		dp[i] = make([]int, i+1)
	}
	dp[0][0] = 1
	for i := 1; i < n; i++ {
		for j := 0; j <= i; j++ {
			if j == 0 || j == i {
				dp[i][j] = 1
			} else {
				dp[i][j] = (dp[i-1][j-1] + dp[i-1][j]) % MOD
			}
		}
	}
	var dfs func(nums []int) int
	dfs = func(nums []int) int {
		if len(nums) <= 1 {
			return 1
		}
		leftNums := make([]int, 0)
		rightNums := make([]int, 0)
		for i := 1; i < len(nums); i++ {
			if nums[i] > nums[0] {
				rightNums = append(rightNums, nums[i])
			} else {
				leftNums = append(leftNums, nums[i])
			}
		}
		leftCnt := dfs(leftNums)
		rightCnt := dfs(rightNums)
		ans := leftCnt * rightCnt % MOD
		ans = ans * dp[len(nums)-1][len(leftNums)] % MOD
		return ans
	}
	return (dfs(nums) - 1 + MOD) % MOD
}
```
